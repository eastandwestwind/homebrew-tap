# Homebrew tap for Perch

[Perch](https://perchfocus.com) is a calm Mac home for your Claude Code sessions.

```sh
brew tap eastandwestwind/tap
brew trust eastandwestwind/tap
brew install --cask perch
```

Recent Homebrew versions ask you to trust a third-party tap before installing from it.

Perch updates itself after you install it. Apple Silicon, macOS 13 or later.
